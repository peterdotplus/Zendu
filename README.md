# Zendu 🍃

Project Managment tool like Trello, but with a focus on multiple smaller projects. I needed this for managing my portfolio of marketing clients, which all had only 1 to 5 tasks, but it was easy to lose the overview when there were more than a couple. Also wanted to implement my idea of a "Zen View", where only one task card is visible in a big full-screen view.

## Orchestrated with Cursor

This is also another experiment with coding with Ai. My main goal is to be able to just give instructions and let the Ai do the rest, like a Senior Developer giving instructions and defined tasks to a Junior Developer.

## Stack

Frontend: TypeScript, React.js, Next.js, Tailwind CSS.

Backend: TypeScript, Node.js, Express.js

Database: SQLite
